# Gamifikasi Alfaqih – Pendidikan Islam Tingkatan 4 & 5

## Tingkatan 4
25 game interaktif (125 misi) berdasarkan buku teks Pendidikan Islam Tingkatan 4 KSSM.

- Halaman utama: `index.html` (senarai semua pelajaran mengikut bidang)
- Setiap pelajaran: `pN/` (P1–P25), kandungan dalam `pN/lesson.js`
- Enjin game dikongsi: `assets/engine.js`, `assets/engine.css`

## Tingkatan 5
21 game interaktif (105 misi) berdasarkan buku teks Pendidikan Islam Tingkatan 5 KSSM dan Nota al-Faqih Ting 5.

- Halaman utama: `t5/index.html`
- Setiap pelajaran: `t5/pN/` (P1–P21), kandungan dalam `t5/pN/lesson.js`
- Enjin game: `t5/assets/engine.js`, `t5/assets/engine.css`
- 20 jenis permainan: Live Quiz, Matching Game, Timed Challenge, Escape Room, Lucky Wheel, Tower Defense, Point Collector, Crossword Puzzle, Mystery Box, Team Battle, Memory Match, True or False, Maze Challenge, Treasure Hunt, Word Search, Spin & Answer, Leaderboard Challenge, Flashcard Battle, Guess the Picture, Level Up Mission
- Nota dalam bentuk flash card bagi setiap pelajaran

Level 1, Level 2, Level 3 · markah, combo, bintang, lencana, sijil, papan juara dan butang kongsi pautan.
